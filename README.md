# algorithm-archive

온라인에서 Java로 코딩 테스트를 연습하고, 제출 코드와 시행착오, 복습 기록을 쌓는 저장소입니다.

프로그래머스 등 온라인 플랫폼에서 코드를 작성하고 실행·채점합니다. 이 저장소에는 문제별 제출 코드와 짧은 풀이 기록을 보관합니다.

## 디렉터리 구조

```text
algorithm-archive/
├── solutions/
│   ├── baekjoon/
│   ├── programmers/
│   └── leetcode/
├── notes/
│   └── README.md
├── templates/
│   └── solution.md
├── .gitattributes
├── .gitignore
└── README.md
```

- `solutions/`: 플랫폼별 Java 제출 코드와 문제별 `README.md`
- `notes/`: 여러 문제에서 반복되는 Java 문법, 알고리즘 개념과 실수 기록
- [templates/solution.md](templates/solution.md): 문제별 풀이 기록 템플릿

## 온라인 풀이부터 기록까지

1. 온라인 플랫폼에서 Java를 선택하고 문제를 풉니다.
2. 예제와 경계 조건을 확인한 뒤 제출하고 채점 결과를 확인합니다.
3. `solutions/<플랫폼>/<문제 번호>/` 폴더에 제출 코드를 저장합니다.
4. `templates/solution.md`를 문제 폴더의 `README.md`로 복사하고 핵심 아이디어와 막힌 점을 짧게 기록합니다.
5. 코드와 기록을 문제 단위로 커밋합니다.

예를 들어 프로그래머스 42586번을 풀면 다음처럼 저장합니다. 아래는 폴더 구성 예시입니다.

```text
solutions/programmers/42586/
├── Solution.java
└── README.md
```

폴더명은 문제 번호로 정하고, 문제 제목과 알고리즘 유형은 `README.md`에 적습니다. 번호가 없는 문제는 플랫폼의 고유 식별자를 사용합니다.

## Java 코드 보관 규칙

- 온라인에 제출한 Java 코드를 그대로 보관합니다. 해결한 문제는 통과한 코드, 미해결 문제는 최근 시도한 코드를 저장합니다.
- 프로그래머스와 LeetCode는 일반적으로 `Solution.java`, 백준은 `Main.java`로 저장하되 문제에서 제공하는 클래스와 메서드 선언을 따릅니다.
- import와 문제 풀이에 필요한 보조 클래스도 제출 코드에 포함했다면 함께 저장합니다.
- 플랫폼에서 제공하는 Java 버전을 확인하고 해당 환경에서 실행·채점합니다.
- 같은 이름의 클래스가 있는 문제들도 각각의 폴더에 독립적으로 보관합니다.

검증은 온라인 플랫폼의 실행·채점을 기준으로 합니다. 직접 확인한 반례나 놓친 경계 조건은 문제별 풀이 기록에 남깁니다.

## 풀이와 복습 기록

- `풀이`: 온라인 채점을 통과했다면 `해결`, 아직 통과하지 못했거나 미제출이면 `미해결`로 기록합니다.
- `도움`: `없음`, `힌트`, `해설` 중 실제 풀이 과정을 나타내는 값을 기록합니다. 해설을 참고해 해결했다면 `풀이: 해결`, `도움: 해설`로 적습니다.
- `복습`: `필요` 또는 `완료`로 기록합니다. 자력으로 해결한 문제도 다시 보고 싶다면 `필요`로 표시합니다.
- 단순한 문제는 핵심 아이디어와 복잡도만 짧게 남겨도 됩니다.
- 틀렸거나 오래 걸린 문제는 원인과 다시 볼 이유를 남깁니다. 미해결 문제는 아직 설명하기 어려운 항목을 비워두어도 됩니다.
- 복습할 때는 기존 설명을 읽기 전에 온라인에서 풀이를 떠올리고 다시 구현합니다.
- 재풀이도 같은 폴더의 코드와 기록을 갱신하고, 복습 날짜와 결과를 추가합니다. 이전 코드는 Git 이력으로 확인합니다.
- 여러 문제에서 반복되는 Java 문법과 실수는 [notes/](notes/README.md)에 모읍니다.

문제 원문은 링크로 연결하고, 풀이를 이해하는 데 필요한 내용만 직접 요약합니다.

## 커밋 규칙

혼자 운영할 때는 `main`에서 문제 단위로 커밋합니다.

```text
solve: pgs 42586 기능개발
attempt: pgs 42586 경계 조건 검토 중
retry: pgs 42586 큐로 재풀이
docs: 이분 탐색 경계 조건 정리
chore: 풀이 템플릿 개선
```

플랫폼 표기는 `boj`, `pgs`, `lc`를 사용합니다. `solve`는 해결한 문제, `attempt`는 미해결 시도, `retry`는 재풀이 기록에 사용합니다. 코드와 해당 풀이 기록은 같은 커밋에 담아도 됩니다.
