# algorithm-archive

코딩 테스트 대비 알고리즘 풀이와 시행착오, 복습 기록을 쌓는 저장소입니다.

문제별로 코드와 풀이 기록을 함께 보관합니다. 풀이 수보다 핵심 아이디어를 이해하고 다시 풀 수 있는지를 중요하게 생각합니다.

## 디렉터리 구조

```text
algorithm-archive/
├── solutions/
│   ├── baekjoon/
│   ├── programmers/
│   └── leetcode/
├── notes/
│   └── README.md
├── templates/
│   └── solution.md
├── .gitattributes
├── .gitignore
└── README.md
```

- `solutions/`: 플랫폼별 문제 풀이 코드와 문제별 `README.md`
- `notes/`: 여러 문제에 활용할 수 있는 알고리즘 개념과 실수 기록
- `templates/solution.md`: 문제별 풀이 기록 템플릿
- `assignments/`: 과제형 문제를 풀게 되면 별도로 추가

## 문제 추가하기

1. 플랫폼 아래에 `<문제 번호>-<영문 이름>` 폴더를 만듭니다.
2. 제출할 코드 파일을 추가합니다.
3. `templates/solution.md`를 문제 폴더의 `README.md`로 복사해 기록합니다.
4. 예제와 경계 조건을 확인하고 문제 단위로 커밋합니다.

예를 들어 Java로 백준 1260번을 풀면 다음처럼 저장합니다.

```text
solutions/baekjoon/1260-dfs-and-bfs/
├── Main.java
└── README.md
```

문제 번호를 기준으로 식별하고 알고리즘 유형은 풀이 기록에 적습니다. 번호가 없는 문제는 플랫폼에서 사용하는 고유 식별자를 사용합니다. 난이도나 풀이 날짜로 폴더를 나누지 않습니다.

사용 언어는 문제에 맞게 선택합니다. Java는 백준의 `Main.java`, 프로그래머스와 LeetCode의 `Solution.java`처럼 각 플랫폼의 제출 규칙을 따릅니다. 다른 언어도 같은 문제 폴더에 보관할 수 있습니다.

## 실행과 검증

각 문제 폴더를 독립적으로 실행합니다. 같은 이름의 `Main`이나 `Solution` 클래스가 여러 개 있을 수 있으므로 전체 풀이를 한꺼번에 컴파일하지 않습니다.

Java 백준 풀이의 실행 예시입니다. JDK 설치가 필요합니다.

```powershell
cd solutions/baekjoon/1260-dfs-and-bfs
javac -encoding UTF-8 Main.java
java Main
```

표준 입력을 사용하는 문제는 실행 후 입력을 전달합니다. 함수 제출형 문제는 플랫폼 실행기나 별도의 로컬 호출 코드로 확인합니다.

플랫폼 예제뿐 아니라 최소 크기, 중복, 경계값 등 해당 풀이에서 실수하기 쉬운 조건을 확인합니다. 공유할 테스트 데이터는 문제 폴더의 `samples/`에 보관할 수 있습니다. 개인 실험 파일은 Git에서 제외되는 루트 `scratch/`에 둡니다.

## 풀이와 복습 기록

- 상태는 `자력 해결`, `힌트 참고`, `해설 참고`, `재풀이 필요` 중 하나로 기록합니다.
- 단순한 문제는 핵심 아이디어와 복잡도만 짧게 남겨도 됩니다.
- 틀렸거나 오래 걸린 문제는 원인과 다음에 확인할 조건을 남깁니다.
- 복습할 때는 기존 설명을 읽기 전에 풀이를 떠올리고 직접 구현해 봅니다.
- 같은 문제의 재풀이는 기존 폴더에서 관리하고, 복습 날짜와 배운 점을 기록합니다.
- 서로 다른 접근을 비교할 필요가 있을 때만 `alternatives/`에 코드를 추가합니다.

문제 원문은 링크로 연결하고, 풀이를 이해하는 데 필요한 내용만 직접 요약합니다.

## 커밋 규칙

혼자 운영할 때는 `main`에서 문제 단위로 커밋합니다.

```text
solve: boj 1260 DFS와 BFS
retry: boj 1260 인접 리스트로 재풀이
docs: 이분 탐색 경계 조건 정리
chore: 풀이 템플릿 개선
```

플랫폼 표기는 `boj`, `pgs`, `lc`를 사용합니다. 풀이 코드와 해당 풀이 기록은 같은 커밋에 담아도 됩니다.

문제 생성 스크립트, 풀이 목록 자동 갱신, CI는 반복 작업이 생길 때 추가합니다.
