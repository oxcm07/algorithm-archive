# 알고리즘 노트

온라인에서 Java로 문제를 풀며 여러 문제에서 반복해서 마주친 문법, 알고리즘 개념, 구현 패턴과 실수를 정리합니다.

- 파일 이름은 `java-pitfalls.md`, `binary-search.md`, `graph-traversal.md`처럼 주제를 나타내는 영문 소문자와 하이픈을 사용합니다.
- 개념 설명과 함께 적용 조건, 복잡도, 주의할 경계 조건을 적습니다.
- Java 실수는 발생 조건과 수정 방법을 함께 적습니다. 예를 들어 정수 범위, 문자열 비교, 컬렉션 사용 중 놓친 조건을 기록합니다.
- 관련 문제의 풀이 폴더를 상대 경로로 연결하면 복습하기 좋습니다.
- 특정 문제에서만 필요한 설명은 해당 문제의 `README.md`에 남깁니다.

노트는 필요한 주제가 생길 때 하나씩 추가합니다.
